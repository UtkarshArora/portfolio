# Utkarsh's portfolio

Goal: show frontend craft. It must not look generic or AI-made. Hand-built interactions, no UI kits.
Stack: Astro, plain CSS (custom properties), vanilla TS islands. No React/Tailwind. Deploy: Cloudflare Pages (free).
Tokens: cream #FFF8EC (bg), burgundy #5B1A2A (text/headings), teal #0F4C45 (accent), rust #C64924 (highlight/CTA). Headings: Georgia serif. Body: system sans.
Motif: an orbit (SVG rings + small planets).
References:

- Rauno Freiberg: 3-column project grid, each tile links to repo/post
- Josh Comeau: playful tactile buttons, custom cursor
- Jhey Tompkins: animated text highlights
- Lynn Fisher: book-like case-study pages, layouts that react to resize; always include a back-to-home link
- Robb Owen / Brittany Chiang: minimal 2-column intro

  Rules: respect prefers-reduced-motion, keyboard accessible, Lighthouse 95+, no layout shift. Leave changes uncommitted after each phase; the user reviews and commits.
